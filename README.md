# One Sentence for a Traveler from 1800

A make.fun bounty entry: a small Node program (`main.ts`) that writes exactly one
sentence — at most 200 characters — explaining the modern internet to a time
traveler who has just stepped out of the year 1800, to `/output/entry.txt`.

The sentence builds only from things a person from 1800 already knows — post
offices, libraries, markets, wires, letters, voices, books — into a single
picture of a world joined by wires, where a letter, a voice, or a whole book
can travel from London to Boston before the ink is dry.
